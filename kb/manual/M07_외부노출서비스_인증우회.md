# M07 외부 노출 서비스 인증 우회 의심
교육용 가상 매뉴얼입니다.

## 판단 기준
- 대출 모집인 조회, 직원 모바일 업무 시스템처럼 외부에서 접근하는 보조 서비스에 로그인 없이 조회한 기록이 있다.
- 세션 검증이 없는 페이지로 다른 고객의 정보가 조회된다.
- 같은 IP에서 짧은 시간에 많은 계정으로 로그인을 시도한다(크리덴셜 스터핑).

## 초동 조치
- 해당 서비스를 임시 중단하거나 접근을 내부망으로 제한한다.
- 다중인증 적용 여부와 세션 검증 누락 페이지를 점검한다.
- 조회된 고객 목록을 뽑아 M04 절차로 넘긴다.

## 보고
- 서비스 중단과 인증 우회 확인 사실을 정보보호최고책임자(CISO)에게 즉시 보고한다.
- 고객 정보가 조회되었으면 M04의 보고 절차를 함께 따른다.
